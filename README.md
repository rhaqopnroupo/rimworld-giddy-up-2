## Overview

Giddy-Up 2 is the fully rewritten successor to the popular Giddy-Up mod, enabling RimWorld colonists and visitors to mount tamed animals for significantly faster overland movement, drafted combat riding with animal-specific bonuses, and caravan travel time reductions. The mod auto-detects rideable animals from any installed content mod and features improved animation integration over the original.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Giddy-Up 2** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Animal Mounting** | Colonists mount tamed animals for 40-100% movement speed increases |
| **Combat Riding** | Draft-mode mounted combat with animal-specific reach and melee bonuses |
| **Caravan Bonus** | Mounted world-map caravans receive meaningful travel time reductions |
| **Universal Compat** | Auto-detects and supports rideable animals from any installed mod |
